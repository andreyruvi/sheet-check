Sheet Check

Read the register before the set goes out.

Paste a sheet list — a Revit or ArchiCAD export, a column out of Excel, or just the numbers — and drop the PDF set anywhere on this page. You get back the numbering gaps, the duplicates, the blank title-block fields, the sheets left on an old revision and the paper sizes that do not match the rest. Nothing is uploaded: the register never leaves this machine.

Numbering convention

@ is a letter and # a digit; add + for one or more and ? to make the token optional. So @+-### matches A-101 and AD-101, and @+-###@? also allows A-101a. For anything else, start the pattern with custom: and write a regular expression.

Required sheets

Separate with spaces or commas. Each is matched however it is written, so A101 and A-101 count as the same sheet.

Title-block fields

Only columns your register actually has can be checked.
